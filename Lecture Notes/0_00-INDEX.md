# CS6750 Human–Computer Interaction — Master Index

**Source:** *Human-Computer Interaction* lecture book, Summer 2017 — lectures by David Joyner, compiled by Shipra De (740 pp.). Converted to one markdown file per chapter with **all lecture content preserved** (verified by automated word-count and sentence-containment audits against the PDF).

**Conventions used in these notes:**
- `»` marks a speaker change in video-transcript dialogue (was `>>` in the book).
- Bold/italic emphasis from the book is preserved. Section headings match the book's lesson videos, including every **Quiz**, **Exercise**, **Paper Spotlight**, and **Design Challenge**.
- Screenshots/figures from the videos are not reproduced (text-only notes); all spoken and written content is included.
- The book's printed header for chapter 4.3 contains a typo ("4.2"); its bookmark and correct number is **4.3 Applications: Domains**.
